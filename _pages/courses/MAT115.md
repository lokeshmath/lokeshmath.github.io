**Offered:** 2025–26 Odd Semester  
**Audience:** First‑year B.Tech. students

### Course Description
A foundational course covering elementary algebra, trigonometry, coordinate geometry, and introductory calculus. Emphasis is placed on problem‑solving and preparing students for advanced engineering mathematics.

### Syllabus Outline
- Algebra: polynomials, equations, inequalities
- Trigonometry: functions, identities, applications
- Coordinate Geometry: lines, circles, conics
- Differential Calculus: limits, derivatives, basic rules
- Integral Calculus: indefinite integrals, basic techniques

### Teaching Materials
- Lecture notes (PDF)
- Weekly tutorial sheets
- Practice problem set with solutions
- Mid‑semester and end‑semester model papers
