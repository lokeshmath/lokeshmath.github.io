**Offered:** 2025–26 Even Semester  
**Audience:** B.Tech. (Industrial, Mechanical, Computer Science, etc.)

### Course Description
Introduces optimisation techniques and decision‑making models: linear programming, transportation, assignment, network models, and basic game theory.

### Syllabus Outline
- Linear Programming: formulation, graphical method, simplex
- Duality and sensitivity analysis
- Transportation and Assignment problems
- Integer Programming (introductory)
- Network models (shortest path, PERT/CPM)
- Game theory: two‑person zero‑sum games

### Teaching Materials
- Lecture notes with solved examples
- Tutorial sheets with real‑world optimisation problems
- Software labs (Excel Solver, Python PuLP)
- Mini‑project on an industrial case

*All content accessible via LMS; recorded lectures available for selected topics.*
